## `04 / ENGINEERING PRINCIPLES`

> **Simple where possible. Robust where necessary. Observable by default.**

- Build maintainable enterprise software.
- Prefer clear architecture over unnecessary complexity.
- Design APIs and services for reliability and evolution.
- Use automation to reduce repetitive engineering work.
- Use AI as an engineering accelerator, with human review and validation.
- Treat testing, monitoring and root-cause analysis as part of development—not afterthoughts.
